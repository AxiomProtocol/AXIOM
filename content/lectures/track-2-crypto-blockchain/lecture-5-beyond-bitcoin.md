## TEACHING POINTS

### 1. Ethereum: The World Computer (2 min)
- Bitcoin = digital gold (store of value)
- Ethereum = programmable money (smart contracts)
- Created by Vitalik Buterin in 2015
- Allows building apps ON the blockchain
- Most tokens are built on Ethereum

### 2. What Are Smart Contracts? (2 min)
- Code that executes automatically when conditions are met
- "If this, then that" - no middleman needed
- Example: Escrow without an escrow agent
- Example: Loans without a bank
- The foundation of DeFi

### 3. Types of Tokens (3 min)
- Utility Tokens: Access to a service (like arcade tokens)
- Governance Tokens: Voting rights in a project
- Stablecoins: Pegged to $1 (USDC, USDT)
- NFTs: Unique tokens (art, membership, property)
- Security Tokens: Represent real assets
- AXM is a governance token for Axiom Protocol

### 4. How to Evaluate a Token (2 min)
- What problem does it solve?
- Who's building it? (Team)
- Is there real usage or just hype?
- Tokenomics: Supply, distribution, utility
- Community: Real users or just speculators?
- If you can't explain it simply, be careful

### 5. Common Scam Red Flags (2 min)
- Promises of guaranteed returns
- Anonymous teams
- No clear use case
- Pressure to buy NOW
- "Get rich quick" messaging
- If it sounds too good to be true...
