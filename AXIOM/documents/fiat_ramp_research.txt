Fiat On/Off Ramp Provider Research — Axiom Protocol (Arbitrum One)
==================================================================
Date: 2025
Target Chain: Arbitrum One (Chain ID 42161)
Target Assets: USDC, USDT, ETH on Arbitrum

Provider Comparison
-------------------

1. MoonPay
   - Supported Regions: 160+ countries (US supported with state restrictions)
   - KYC Requirements: L1 (email + name) up to $150; L2 (ID + selfie) for higher limits
   - Fees: 4.5% card, 1% bank transfer (min $3.99)
   - Arbitrum Support: Yes — native Arbitrum One for ETH, USDC
   - Stablecoin Support: USDC, USDT on Arbitrum
   - Integration Complexity: Low — drop-in widget (iframe/SDK), REST API available
   - Minimum Integration Time: 1–2 weeks (widget), 3–4 weeks (custom API)
   - Notes: Mature product, strong compliance, popular in DeFi. Supports off-ramp (sell crypto to fiat).

2. Transak
   - Supported Regions: 170+ countries, 46 US states
   - KYC Requirements: Tiered — basic (name + DOB) for small amounts; full ID for higher
   - Fees: 1%–5% depending on payment method and region
   - Arbitrum Support: Yes — Arbitrum One for ETH, USDC, USDT
   - Stablecoin Support: USDC, USDT on Arbitrum
   - Integration Complexity: Low — widget SDK (React, JS), REST API
   - Minimum Integration Time: 1–2 weeks
   - Notes: Developer-friendly, good documentation, supports off-ramp. Free sandbox for testing.

3. Ramp Network
   - Supported Regions: 150+ countries, US supported (state restrictions apply)
   - KYC Requirements: Automated ID verification, selfie match
   - Fees: 0.49%–2.49% (varies by payment method)
   - Arbitrum Support: Yes — native Arbitrum One
   - Stablecoin Support: USDC on Arbitrum
   - Integration Complexity: Low — hosted widget, SDK, deep-link integration
   - Minimum Integration Time: 1 week (widget)
   - Notes: Competitive fees, clean UX, supports off-ramp. Apple Pay / Google Pay supported.

4. Coinbase Onramp (formerly Coinbase Pay / CBPay)
   - Supported Regions: 100+ countries, strong US coverage
   - KYC Requirements: Coinbase account required (Coinbase handles KYC)
   - Fees: Coinbase standard fees (1.49% bank, 3.99% card)
   - Arbitrum Support: Yes — Arbitrum One for ETH, USDC
   - Stablecoin Support: USDC on Arbitrum
   - Integration Complexity: Medium — requires Coinbase Developer Platform registration, SDK integration
   - Minimum Integration Time: 2–3 weeks
   - Notes: Trusted brand, high user trust factor. Users need Coinbase account. Good for US-focused audience.

5. Mt Pelerin
   - Supported Regions: 50+ countries (primarily EU/EEA, Switzerland), limited US support
   - KYC Requirements: Swiss-regulated KYC, full ID verification
   - Fees: 1.3%–2.5% (competitive for EUR)
   - Arbitrum Support: Yes — Arbitrum One supported
   - Stablecoin Support: USDC, USDT on Arbitrum
   - Integration Complexity: Medium — widget integration, API available
   - Minimum Integration Time: 2–3 weeks
   - Notes: Strong regulatory compliance (Swiss FINMA), best for European users. Non-custodial focus.

Recommendation
--------------
Primary: Transak or Ramp Network — both offer broad region coverage, native Arbitrum support,
competitive fees, and simple widget integration (1–2 weeks). Transak has wider US state coverage;
Ramp has lower fees.

Secondary: MoonPay — mature product with strong brand recognition, though higher card fees.

Consideration: Coinbase Onramp for US-focused users who already have Coinbase accounts.

Integration Plan
----------------
Phase 1: Embed Transak or Ramp widget on /onramp page with pre-filled Arbitrum + USDC parameters.
Phase 2: Add off-ramp flow (sell USDC back to fiat).
Phase 3: Evaluate multi-provider aggregation for best rates across providers.
