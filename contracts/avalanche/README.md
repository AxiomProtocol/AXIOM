# Avalanche Contracts Namespace (Phase 1 Fuji)

This folder is reserved for Avalanche-specific contracts if/when Phase 1 deployment code requires chain-specific wrappers.

For this foundation phase, contract design reuses existing ERC-3643 patterns from `contracts-axusd-3643/` and does not introduce new Avalanche production contracts.

Arbitrum remains canonical for identity, reserve accounting, issuance, policy, and solvency/disclosure.
