## ACCREDITATION VERIFICATION PROCEDURES

### Income Verification

1. Request tax returns (Form 1040) for past 2 years
2. Verify income exceeds $200K individual / $300K joint
3. Request current year income attestation
4. Document verification in investor file
5. Note verification method and date

### Net Worth Verification

1. Request recent bank/brokerage statements (within 90 days)
2. Request real estate appraisals for investment properties
3. Calculate net worth excluding primary residence
4. Verify exceeds $1M threshold
5. Document calculation and source documents
6. Note verification method and date

### Third-Party Verification

1. Request letter from CPA, attorney, or broker-dealer
2. Verify letter is dated within 3 months
3. Confirm letter states professional has verified status
4. Verify professional credentials
5. Document letter and verification in investor file

### Minimum Investment Verification (2025 Guidance)

1. Confirm investment is $200K+ (individual) or $1M+ (entity)
2. Obtain written self-certification of accredited status
3. Obtain representation that investment is not financed
4. Document certification in investor file

## EMERGENCY PROCEDURES

### Smart Contract Issue

1. Pause deposits if possible
2. Contact blockchain security firm
3. Assess scope of issue
4. Communicate with investors
5. Implement fix and verify
6. Resume operations with enhanced monitoring

### Major Loan Default

1. Activate default management procedures
2. Assess recovery options
3. Initiate legal action if necessary
4. Update investors on impact
5. Draw on loss reserves if needed
6. Document all actions taken

### Regulatory Inquiry

1. Engage securities counsel immediately
2. Preserve all relevant documents
3. Prepare timeline of events
4. Cooperate with regulators
5. Communicate with investors as appropriate
