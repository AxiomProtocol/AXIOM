  - [ ] Fund wallet address
  - [ ] Today's date
  - [ ] Any specific terms you want to change
☐ **Convert documents to PDF** for professional presentation
☐ **Create investor portal** (can use Google Drive, Dropbox, or build into Axiom site)

### PHASE 3: SEC EDGAR SETUP (Week 2)
☐ **Create EDGAR account:**
  1. Go to: https://www.sec.gov/edgar/filer-information/how-do-i-become-edgar-filer
  2. Complete Form ID application
  3. Wait 2-3 business days for CIK number
  4. Activate account
☐ **DO NOT file Form D yet** - wait until you have your first investor

### PHASE 5: FIRST INVESTOR (When Ready)
