# Steward-Activated Land Program - Standard Operating Procedures

## Weekly Operating Cadence

### Monday: Planning
- [ ] Review active cycles and upcoming activities
- [ ] Check owner communication needs
- [ ] Update task board with week's priorities
- [ ] Confirm participant availability for scheduled activities

### Tuesday-Thursday: Field Operations
- [ ] Conduct scheduled activities on activated land
- [ ] Take photos of progress
- [ ] Note any issues or concerns
- [ ] Brief participants on next session

### Friday: Documentation
- [ ] Complete weekly logs for all active cycles
- [ ] Send owner updates (if weekly cadence)
- [ ] Update lead stages in dashboard
- [ ] Flag any urgent issues

### Weekend: Outreach
- [ ] Review landowner leads pipeline
- [ ] Prepare outreach for new prospects
- [ ] Follow up on pending conversations

## Checklists

### Land Intake Checklist
- [ ] Owner full legal name confirmed
- [ ] Primary contact method established
- [ ] Property address/parcel recorded
- [ ] Acreage confirmed
- [ ] Current land use documented
- [ ] Owner goals discussed
- [ ] Restrictions or concerns noted
- [ ] Photos obtained (if available)
- [ ] Next steps communicated
- [ ] Intake form saved to dashboard

### Access & Safety Checklist
- [ ] Legal access route confirmed
- [ ] Gate/key arrangements made
- [ ] Parking area identified
- [ ] Emergency vehicle access verified
- [ ] Water source identified and tested
- [ ] Hazards identified and marked
- [ ] Property boundaries understood
- [ ] Cell service or communication plan
- [ ] First aid kit location designated
- [ ] Emergency contacts created

### Stewardship Plan Checklist
- [ ] Proposed activities described
- [ ] Seasonal calendar included
- [ ] Participant guidelines documented
- [ ] Max participant count defined
- [ ] Communication frequency agreed
- [ ] Preferred update method documented
- [ ] Access hours specified
- [ ] Tool/equipment storage arranged
- [ ] Insurance acknowledgment included
- [ ] Stop/pause procedures documented
- [ ] Plan shared with owner
- [ ] Owner questions addressed
- [ ] Written approval obtained

### Activation Cycle Readiness Checklist
- [ ] Stewardship plan approved
- [ ] Site prepared (cleared, marked, ready)
- [ ] Water access confirmed
- [ ] Tools and equipment staged
- [ ] Participants recruited and briefed
- [ ] Participant waivers signed
- [ ] First activity scheduled
- [ ] Owner notified of start date
- [ ] Emergency plan in place
- [ ] Documentation system ready

### Weekly Operations Checklist
- [ ] Activity log updated
- [ ] Attendance recorded
- [ ] Progress photos taken
- [ ] Issues documented
- [ ] Owner update sent (if applicable)
- [ ] Next week activities confirmed
- [ ] Participant needs addressed
- [ ] Site condition checked
- [ ] Dashboard updated

## Escalation Procedures

### Minor Issues
- Document in weekly log
- Address with participants
- Inform owner in next regular update

### Moderate Issues
- Document immediately
- Pause affected activities if needed
- Contact owner within 24 hours
- Note in incident log

### Serious Issues
- Stop all activities immediately
- Contact owner same day
- Notify Axiom coordination team
- Document thoroughly
- Do not resume without approval

## Quality Standards

### Minimum Documentation
- Weekly log for each active cycle
- Photos at least bi-weekly
- Owner update per agreed frequency
- Dashboard updated within 48 hours of changes

### Response Times
- Owner questions: Within 24 hours
- Participant issues: Same day
- Emergency situations: Immediate
- Lead follow-ups: Within 72 hours

### Site Standards
- Clear of hazards before each session
- Tools stored securely
- No unauthorized structures
- Respect property boundaries
- Leave cleaner than found
