## How to use this tracker

1. Update each candidate's row when an outreach action is taken or a response is received.
2. File all received documents in the C-02 evidence folder and record the filename in the Notes column.
3. Score each MC (MC-01–MC-07) only after a formal written RFP response is received.
4. Score each OQ (OQ-01–OQ-16) based on whether the response meaningfully addresses the question.
5. Update the evaluation matrix (AXAG_CUSTODY_EVALUATION_MATRIX.md) to version 2.0 for each candidate once their formal response is received and scored.
6. Report all status changes to the Treasury Lead and Compliance Lead.
7. Do not update Selection Readiness to READY unless all applicable MCs and PREs are satisfied.
